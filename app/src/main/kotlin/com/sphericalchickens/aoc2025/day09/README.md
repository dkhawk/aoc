## Setup

Sliding down a firepole from the playground, you land in the North Pole base movie theater.
The theater floor has a large tile floor grid. The Elves are redecorating by switching out square tiles, some of which are red tiles (`#`).

## Solution

### Part 1

We find the largest rectangle that can be formed on the grid using two red tiles as opposite corners.

### Part 2

Part 2 considers restrictions on tile regions and calculates the maximum area bounding box fitting the decorative constraints.
