## Setup

Fit 150 liters of eggnog into a set of available container capacities.

## Solution

### Part 1

Use subset-sum recursion or bitmask combination search to count all combinations of containers that sum to exactly 150 liters.

### Part 2

Find the minimum number of containers used in any valid combination and count how many combinations use that exact minimum number.
