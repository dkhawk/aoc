# Advent of Code Calendar and Days Structure

- **2015 – 2024**: The original Advent of Code (AoC) events have **25 days** (December 1 through December 25).
- **2025 onwards**: Starting in 2025, Advent of Code was reduced to **12 days** (December 1 through December 12).
- When creating placeholders, benchmarks, calendar visualizations, documentation grids, or fetching inputs:
  - For years 2015 through 2024: expect 25 days.
  - For year 2025 and beyond: expect exactly 12 days. Days 13–25 do not exist.
