## Setup

Jumping down a ventilation duct, you land in a cavernous underground Christmas tree farm.
The Elves are placing presents under the trees, but presents come in non-standard polyomino shapes and must fit perfectly into grid regions under each tree without overlapping or stacking.

## Solution

### Part 1

We model present packing into 2D unit grids for each Christmas tree region.

### Part 2

Part 2 computes optimal polyomino placement configurations across all regions to ensure all presents fit under the trees before Christmas.
